# Sonimi Studio SEO checklist

## Implemented in this package
- Unique title tags and meta descriptions on all indexable HTML pages.
- Self-referencing canonical URLs.
- Robots meta directives, with the thank-you page set to `noindex, nofollow`.
- Open Graph and Twitter Card metadata.
- Descriptive portfolio image filenames and alt text retained/improved.
- Image width/height attributes where dimensions are available, plus lazy loading/async decoding for below-the-fold images.
- One primary H1 per page with logical case-study H2 content.
- JSON-LD for Organization, WebSite and ProfessionalService on the homepage.
- JSON-LD BreadcrumbList and CreativeWork on case-study pages.
- Updated XML sitemap containing all seven canonical, indexable pages.
- robots.txt points crawlers to the sitemap.
- Internal links between homepage, case studies and contact section retained.

## After deployment
1. Open every page on the live site and confirm images, navigation and forms work.
2. Add/verify `https://sonimistudio.com.au/` in Google Search Console.
3. Submit `https://sonimistudio.com.au/sitemap.xml`.
4. Use URL Inspection for the homepage and each new case study, then request indexing where appropriate.
5. Test structured data with Google's Rich Results Test / Schema Markup Validator.
6. Run PageSpeed Insights on mobile and desktop. Replace temporary SVG case-study covers with compressed real project images when ready.
7. Keep Google Business Profile details consistent with the website and continue earning genuine reviews/citations.
8. Add useful service/location content only where it genuinely helps visitors. Avoid repetitive location/keyword stuffing.

## Important
Technical/on-page SEO makes the site crawlable and understandable, but does not guarantee rankings. Search performance also depends on content quality, competition, authority/links, local signals, reviews, performance and ongoing maintenance.
